Shows the time of each message in the thread chat.

- Each message that you send shows "Sent 2:10 PM" under it.
- The last Claude message of a reply shows "Finished 2:14 PM". This is the time that Claude stopped work. An interrupted reply shows "Stopped", and a failed reply shows "Failed".
- Each other Claude message shows the time that it arrived.
- A message from an earlier day also shows the date, such as "Sent Oct 29, 2:10 PM".
- Put the pointer on a message to see the full date and time.

The plugin reads the message times from the bb server on this computer. It does not read the message text.

A bb update can change the chat page. If that occurs, the labels can stop showing. The chat continues to work.
